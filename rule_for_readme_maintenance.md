When updating the Library Management System project

- Always check if README.md in trickle/notes needs to be updated
- Update README when:
  - New features are added
  - Project structure changes
  - New pages or components are created
  - Database schema is modified
  - Important functionality changes
  - New technology or library is integrated
- Keep the README concise and focused on key information
- Include updated login credentials if they change
- Document any new workflows or user processes
